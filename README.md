# 博物声 · 博物馆展陈脚本工作台

面向博物馆内容团队的展陈脚本编写、审校与版本管理工具。项目按“展厅 → 展项 → 语言”组织内容，覆盖标题、讲解词、无障碍描述、朗读时长和资料来源。

## 功能

- 展厅、展项切换，以及中文、英文、日文多语言稿件进度对照。
- **段落对齐**：以中文母版段落为锚，英 / 日译稿逐段对位，同一展项三语按行并排。
- **母版联动**：母版段落改版（修订号递增）后，锚定它且未锁定的译稿段自动回到“待复核”；已定稿锁定段落内容、锁和复核结论照旧保留，仅提示“母版已更新·定稿保留”。
- 母版段支持拆分、合并、删除；结构变化后原译稿段带内容进入“待接入清单”，可重新对位到新母版段。
- **旧译稿接入**：JSON 批量导入（支持 `{drafts:[...]}` 或单份 `{language, segments}`，缺分段时可用空行切分 narration）。段数与母版一致且对位格为空时自动按段对位（待复核），否则按语言收入待接入清单；只填空字段、绝不覆盖已有文稿；整份校验失败时整体回滚到接入前，且不占用撤销栈。
- 历史本地数据（v1）打开时自动迁移：补修订号并按段落序号建立基线对位。
- 草稿、待审、退回、已定稿四态流转；已确认段落可锁定，避免误改。
- 分段校对、预计朗读时长、自动字数/语速估算和来源核验。
- 完整版本快照、句子级差异比较和版本恢复（恢复后按当前母版重算对位状态）。
- 桌面、平板、手机、馆内触摸屏四种排版预览。
- 浏览器本地持久化，刷新后恢复；最多 50 步撤销重做。
- `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z`、`Ctrl/⌘ + S` 快捷键与语义化表单标签。

### 旧译稿 JSON 格式

```json
{
  "drafts": [
    {
      "language": "en",
      "title": "可选标题，仅在该字段为空时填入",
      "segments": [
        { "label": "段落标签（可选）", "content": "译文内容（必填）" }
      ]
    }
  ]
}
```

`language` 仅接受 `en` / `ja`（中文为母版，不接受导入）。接入对话框内置“填入示例”按钮。

## 技术栈

- Nuxt 3、Vue 3、TypeScript、Pinia
- Vuetify 3
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

开发服务器默认监听 `http://localhost:3000`。应用不包含宿主端口配置。

## 生产构建

```bash
npm install
npm run build
```

静态产物位于 `.output/public`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1004 .
docker run --rm -p 10004:80 sologsb-1004
```

容器内 nginx 监听 80，静态单页回退到 `index.html`。根据根端口表，本地映射为宿主 `10004`。

## 数据说明

所有数据只保存在当前浏览器。清除站点数据会删除本地稿件；版本快照保存在同一份本地数据中。
